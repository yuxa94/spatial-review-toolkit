# 패키지에 스킬 추가하기

현재 포함된 스킬은 다음과 같다.

- `skills/spatial-review-workflow/SKILL.md`: 새 도면 프로젝트 생성, 검증, 캡처와 외부 이미지 시각화 인계. `Install-skills.command`/`.bat`로 이 워크플로를 호출하는 Codex 스킬을 설치할 수 있다.

- `skills/spatial-input/SKILL.md`: 원본 도면 입력 검사
- `skills/interior-visualization/SKILL.md`: 저장된 실내 뷰·레퍼런스·마감 주석을 사용한 대화형 이미지 생성과 버전 등록
- `skills/pedestrian-journey/SKILL.md`: 자연어 방문 동선을 장애물 검증 경로와 보행 애니메이션으로 구현

입력 스킬은 PNG/PDF/DXF/DWG/IFC 입력 검사, 원본 정보와 가정 구분, 기존 공간 구조를 보존한 모델 구성 지침을 담는다. 해당 SKILL.md를 Codex/Astra에 읽고 작업하도록 요청할 수 있다. 자동 검색이 필요하면 이 스킬 폴더 전체를 사용 환경의 Codex skills 디렉터리에 설치한다. 패키지 배포만으로 전역 설치되지는 않는다.

추가 스킬 요청에는 다음 세 가지가 있으면 충분하다.

- 사용자가 할 요청의 예: “라운지만 따뜻한 호텔 느낌으로 바꿔 줘.”
- 반드시 유지할 조건: 벽·기둥·보이드·가구 위치 고정 등.
- 원하는 결과: 3D 장면, 동일 시점 비교 이미지, 재료 보드, 보고서 등.

각 기능은 `skills/<skill-name>/SKILL.md`에 목적과 실행 지침을 두고, 필요한 반복 작업만 스크립트로 만든다. 입력 처리 → 고정 구조 검증 → 컨셉 적용 → 이미지 생성/비교 → 전달처럼 역할을 나눌 수 있다. 기능 수를 미리 고정하지 않는다.

이미지 생성 기능을 추가할 경우 사용하는 Codex/Astra 환경에 이미지 생성 도구가 실제 제공되는지 먼저 확인한다. 스킬 텍스트만으로 없는 도구가 생기지는 않는다. 이번 패키지는 이미지 생성 API나 결제 계정을 연결하지 않는다.
