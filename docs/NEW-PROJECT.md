# 다른 도면으로 사용하기

이 패키지는 로컬 Three.js 앱과 도면 작업 스킬입니다. Node.js 20 이상이 필요합니다. 실행에 npm 설치/API 키는 필요하지 않습니다. 3D 화면은 WebGL2가 가능한 브라우저가 필요합니다.

## 처음 한 번

1. `spatial-review-toolkit-0.6.1.zip`을 작업용 위치에 압축 해제합니다.
2. `Start.command`(Mac) / `Start.bat`(Windows)로 합성 예제를 확인합니다.
3. 선택 사항: `Install-skills.command` / `Install-skills.bat`로 Codex에 `igis-spatial-review` 스킬을 등록합니다. 설치는 실행한 사용자의 Codex skills 폴더에 래퍼만 추가합니다. 패키지 자체는 이동하지 마세요. 전역 설치 없이 SKILL.md의 경로를 대화에 지정해도 됩니다.

## 다음 도면부터는 대화로 요청

> $igis-spatial-review 이 도면으로 새 공간 검토 프로젝트를 만들어 줘. 기존 프로젝트는 유지하고 별도 폴더에 구성해 줘. 벽·기둥·보이드·문을 먼저 맞추고, 영역과 가구를 구분해 줘. 실내 뷰와 좌표 코멘트, 보행 동선을 사용할 수 있게 해 줘. AI 이미지는 외부에서 만들 예정이므로 PNG를 captures 폴더에 저장해 줘.

스킬은 도면을 검사하고 모델 데이터 작성과 검증을 돕습니다. 도면을 선택하는 것만으로 자동으로 모든 3D 형상이 생성되지는 않습니다. 길이·높이·가구 종류가 불명확하면 확인/가정 단계가 필요합니다.

## 도면별 지원 경로

| 입력 | 직접 가능한 작업 | 전체 스튜디오로 사용 |
| --- | --- | --- |
| PNG/JPEG | 원본 보기 | 에이전트가 도면을 추적해 모델 JSON 구성 |
| PDF | 페이지 미리보기 | 선택 페이지 이미지/벡터를 근거로 모델 구성 |
| ASCII DXF | 선·레이어 검사 | 벽/방/문 의미를 확인하고 모델 구성 |
| DWG | 직접 파싱 불가 | CAD에서 DXF/IFC로 내보내기 필요 |
| IFC | 형상·객체·층 검사 | 원본 BIM 직접 스튜디오 연결은 미지원. 별도 어댑터 또는 명시된 단순화 모델 필요 |

## 모델을 준비한 경우

```
node scripts/new-project.mjs ../my-building ./my-model.json ./drawing.png
```

PDF/CAD를 원본으로 보관하고 좌표가 맞는 PNG를 별도로 제공하려면 네 번째 인수를 추가합니다. 새 폴더는 패키지 밖에 만들며 기존 폴더는 거부합니다. 원본/개인 코멘트/레퍼런스/생성 결과가 다른 프로젝트로 섞이지 않습니다.

새 폴더의 `Start.command` / `Start.bat`를 실행합니다. 이미 서버가 있으면 다음 포트를 자동 선택하므로 새로 표시되는 주소로 들어가세요. 프로젝트마다 자신의 모델과 `project/review.json`, `project/assets/`, `captures/`를 사용합니다.

`model.json`을 수정한 뒤 `node scripts/sync-model.mjs`로 반영합니다. 잘못된 데이터는 활성 모듈을 교체하지 않습니다. 같은 ID의 의미나 좌표계를 바꾸면 저장된 코멘트·카메라가 맞지 않게 됩니다. 큰 변경은 새 프로젝트로 만드세요.

## 외부 이미지 시각화

실내 카메라를 잡아 **현재 뷰 캡처·저장**을 누르면 `captures/날짜_뷰이름_ID.png`와 같은 이름의 카메라 `.json`이 생성됩니다. 원본 파일은 매번 별도로 저장합니다. 화면에 저장 경로와 PNG 다운로드 링크가 표시됩니다.

**저장 폴더 선택**은 지원 브라우저에서 원하는 폴더에 PNG를 추가 저장합니다. 선택은 현재 탭에만 유지되며 새로고침 후 다시 선택합니다. 선택 폴더 권한이 없거나 저장에 실패해도 기본 captures 파일과 프로젝트 뷰는 유지됩니다. 미지원 브라우저는 기본 폴더/다운로드를 사용합니다.

외부 이미지 도구에 PNG와 지시를 전달하세요: “카메라·벽·기둥·문·가구의 위치와 개수를 유지하고, 지정한 마감/조명만 변경.” 결과를 받아 **이미지·마감 → 생성된 이미지 버전 추가**로 보관할 수 있습니다. 패키지는 외부 서비스를 자동으로 호출하지 않습니다.

## 보관과 이동

새 프로젝트 폴더 전체를 복사하면 됩니다. `project/`와 `captures/`, `sources/`, 모델 파일을 빠뜨리지 마세요. 공개 패키지에는 합성 예제만 포함됩니다. 개인 도면·코멘트·캡처·생성 이미지는 사용자의 로컬 프로젝트에 저장됩니다.
