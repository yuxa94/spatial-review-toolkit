# 작업 프로세스와 기능

1. 입력 검토: 파일 형식, 층, 단위, 기준 치수와 누락 요소를 확인한다.
2. 구조 구성: 외곽, 보이드, 벽과 개구부, 기둥을 먼저 모델링한다.
3. 가구와 영역: 실별 ID와 가구 종류·좌표·방향을 원본과 비교한다.
4. 공간 검토: 조감도와 실내 카메라, 가정 천장으로 구도와 관계를 확인한다.
5. 협업: 좌표 코멘트와 작성 시점, 해결 상태를 저장한다.
6. 외부 이미지 시각화: captures 폴더의 PNG와 카메라 JSON을 사용한다. 원본과 결과 버전을 분리한다.
7. 보행: 통행 가능한 정지점을 연결하고 재생·녹화한다.
8. 인계: 프로젝트 폴더 전체를 전달한다.

구현된 기능: 공간/레이어 선택 동기화, 좌표 코멘트, 실내 캡처, 한/영 무관 WASD, 장애물 접촉 시 슬라이딩, 실내 천장, 모델 검증, 별도 프로젝트 생성, 보행 경로·녹화, PDF/DXF/IFC 입력 검사.

실내 렌더링은 필요한 때만 실행하며 이동/녹화는 최대 30fps, 픽셀 비율은 1.5로 제한한다. 브라우저의 WebGL 차단을 해제하지 않는다. 이미지 생성은 기본적으로 외부 도구를 이용한다. 대화 이미지 도구 연계 스킬은 선택 사항이며 특정 생성 모델을 보장하지 않는다.

이 모델은 공간 컨셉 소통용이다. 도면에 없는 치수·높이·제품 상세를 확인된 사실처럼 다루지 않는다. 임의 도면의 무검토 자동 3D 변환, IFC 전체 BIM 편집, 다층 건물, 실시간 다중 사용자 협업은 현재 지원하지 않는다.
