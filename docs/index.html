1

설치하고 첫 화면 열기

처음에는 합성 라운지·회의실 예제로 기능을 확인합니다. 도면과 작업 파일은 로컬에 저장되며, 실행에 API 키나 npm 설치가 필요하지 않습니다.

  1. 실행 환경 준비

    Node.js 공식 사이트에서 20 이상을 설치합니다. 최신 Chrome·Edge 등 WebGL2 지원 브라우저를 준비하세요.

  2. 패키지 내려받기

    실행 패키지 ZIP을 다운로드하고 압축을 풉니다. 압축 파일 안에서 실행하지 말고 폴더 전체를 꺼내세요.

  3. 운영체제에 맞게 실행

    Start.command를 실행합니다. 실행이 차단되면 터미널에서 패키지 폴더로 이동한 뒤 아래 명령을 실행하세요.

    Start.bat를 실행합니다. Node를 찾지 못하면 Node.js 설치 후 터미널을 다시 여세요.

    패키지 폴더에서 아래 명령을 실행합니다. 종료할 때는 터미널에서 Ctrl + C를 누릅니다.

    node server.mjs --open

  4. 로컬 주소 확인

    기본 주소는 http://127.0.0.1:4187입니다. 이미 실행 중이면 다음 포트를 선택하므로, 터미널에 표시된 주소로 접속하세요. 서버 터미널을 닫으면 저장 기능도 중단됩니다.

HTML을 직접 더블클릭하지 마세요.

실행 앱은 로컬 서버가 필요합니다. 이 공개 가이드와 달리 index.html을 file://로 열면 모듈과 저장 기능이 정상 동작하지 않습니다.

다른 도면으로 새 프로젝트 만들기

도면마다 별도 폴더를 만듭니다. 이전 도면의 코멘트나 카메라를 새 모델에 섞지 않고, 각 프로젝트의 원본과 작업 기록을 함께 보관하기 위한 방식입니다.

가장 쉬운 방법: 스킬과 대화로 요청

패키지의 Install-skills.command(Mac) 또는 Install-skills.bat(Windows)를 실행하면 Codex에 igis-spatial-review 스킬이 등록됩니다. 새 대화에서 사용할 수 있습니다. 설치 후 패키지 위치를 옮기면 스킬에 연결된 경로도 다시 확인해야 합니다.

도면을 첨부한 뒤 이렇게 요청하세요

$igis-spatial-review 이 도면으로 별도 공간 검토 프로젝트를 만들어 줘. 기존 프로젝트는 유지해 줘. 벽·기둥·보이드·문을 먼저 맞추고, 영역과 가구를 구분해 줘. 실내 뷰, 좌표 코멘트, 보행 동선을 사용하고 싶어. AI 이미지는 외부에서 만들 예정이므로 PNG를 captures 폴더에 저장할 수 있게 해 줘.

스킬을 설치하지 않아도 패키지의 skills/spatial-review-workflow/SKILL.md 경로를 대화에 알려주고 읽도록 요청할 수 있습니다. 스킬은 작업 절차를 안내하며, 실행 환경에 없는 이미지 도구나 CAD 기능을 추가하지는 않습니다.

3

구조와 가구 배치 먼저 검토하기

보기 좋은 이미지보다 먼저 확인할 것은 원본과의 관계입니다. 층의 외곽, 보이드, 기둥, 문 위치와 가구 방향을 차례로 대조하세요.

기본 조작

  • 왼쪽 드래그: 회전
  • 휠: 확대·축소
  • 오른쪽 드래그: 화면 이동
  • 공간·가구 클릭: 객체 선택과 왼쪽 목록 연동
  • 목록 눈 아이콘: 영역 표시·숨김

검토에 유용한 버튼

  • 평면: 위에서 배치 비교
  • 원본 도면 겹치기: 좌표가 맞는 PNG와 비교
  • 선택 공간 보기: 선택 영역 확대
  • 이 영역만 표시: 다른 영역 숨김
  • 벽 표시 높이: 내부를 보기 위한 단면 표현

좌석은 테이블을 향하는지, 소파의 L자 방향은 맞는지, 보이드와 문을 가구가 막고 있지는 않은지 확인합니다. 벽 표시 높이를 낮추는 것은 조감도 표시만 바꾸며, 원본 치수를 수정하지 않습니다.

미리보기 PNG가 없는 프로젝트에서는 원본 겹치기가 비활성화됩니다. 도면 치수와 실제 정확도는 별도 검증이 필요합니다.

4

사람 눈높이에서 실내 뷰 잡기

  1. 공간을 선택한 뒤 인테리어 뷰를 누릅니다.
  2. 시작 위치(남·북·동·서)를 정하고 실내 뷰 잡기를 누릅니다.
  3. 3D 화면을 클릭해 포커스를 둡니다. 드래그로 둘러보고 키보드로 이동합니다.
  4. 눈높이와 화각을 조절합니다. 기본 눈높이는 1.6m, 화각은 65°입니다.
W앞으로
A왼쪽
S뒤로
D오른쪽

한글·영문 입력 상태와 관계없이 물리적인 WASD 위치로 이동합니다. 벽이나 가구에 닿으면 가능한 방향으로 미끄러지며, 장애물을 관통하지 않습니다. 입력 칸에서 글을 쓰고 있다면 먼저 3D 화면을 클릭하세요.

천장과 높이는 모델 설정을 따릅니다.

실내 뷰·캡처·영상에는 천장이 보이고 조감도는 내부가 보이도록 열려 있습니다. 도면에 높이나 보이드 상부 정보가 없다면 모델 정보의 가정을 확인하세요.

5

실내 뷰를 PNG로 폴더에 저장하기

외부 AI 이미지 도구에는 이 PNG를 전달하면 됩니다. 캡처에 패널과 코멘트 핀은 포함되지 않으며, 저장 크기는 1280 × 720입니다.

  1. 실내 카메라에서 구도를 잡고 뷰 이름을 입력합니다.
  2. 선택 사항: 저장 폴더 선택으로 원하는 폴더를 지정합니다.
  3. 현재 뷰 캡처·저장을 누릅니다.
  4. “PNG를 저장했습니다” 상태와 버튼 아래의 저장 경로를 확인합니다.
현재 뷰 캡처·저장
기본 저장프로젝트/captures/날짜_뷰이름_ID.png같은 이름의 .json에 카메라 위치·시선·화각 저장
선택한 폴더폴더를 지정했다면 PNG를 추가 저장
  • 기본 폴더는 항상 유지됩니다. 선택 폴더 저장에 실패해도 기본 캡처와 저장된 뷰는 남습니다.
  • 같은 뷰 이름을 사용해도 고유 ID가 붙어 기존 파일을 덮어쓰지 않습니다.
  • 마지막 캡처 PNG 다운로드 링크로도 저장할 수 있습니다.
  • 선택 폴더는 현재 탭에서만 유지됩니다. 새로고침 후에는 다시 선택합니다.
  • 폴더 선택은 지원 브라우저에서만 동작합니다. 미지원 환경에서는 기본 폴더와 다운로드를 사용하세요. 브라우저 지원 안내
저장했던 구도에서 다시 캡처하려면

실내 카메라의 저장된 뷰에서 항목을 고르고 카메라 복원을 누릅니다. 천장·모델을 수정한 뒤에도 같은 카메라에서 새 파일을 만들 수 있습니다. 이전 캡처 이미지는 자동으로 바뀌지 않습니다.

6

공간의 정확한 위치에 의견 남기기

상단 코멘트를 켜면 오른쪽 패널과 좌표 핀이 나타납니다. 기본값은 숨김이며, 끄면 검토 화면을 넓게 사용할 수 있습니다.

  1. 위치에 코멘트 남기기를 누릅니다.
  2. 3D의 벽·바닥·가구 표면을 클릭합니다.
  3. 오른쪽에 의견을 입력하고 저장합니다.
  4. 번호 핀 또는 코멘트 카드로 다시 선택합니다.

위치와 시점을 함께

작성 시점 보기는 의견을 남겼을 때의 카메라를 복원합니다. 조감도와 실내 화면을 오가며 같은 대상을 확인할 수 있습니다.

검토 상태 정리

공간별·미해결 필터, 해결 처리와 다시 열기를 사용합니다. 특정 지점이 필요 없으면 공간 전체 의견을 남깁니다. 다른 탭의 의견은 패널에서 새로고침합니다.

코멘트는 현재 모델의 ID와 좌표에 연결됩니다. 새 도면이나 좌표계로 바꾸면 이전 의견의 위치가 맞지 않을 수 있습니다. 다중 사용자 실시간 동기화 서비스는 아닙니다.

7

사용자 동선을 따라 걷고 녹화하기

예를 들어 “입구에서 라운지를 거쳐 회의실로 이동”하는 체험을 보행자 시점으로 설명할 수 있습니다. 실제 통행 가능한 지점을 연결하며, 동선을 위해 임의로 벽이나 문을 바꾸지 않습니다.

화면에서 만들기

  1. 카메라를 출발 위치로 이동합니다.
  2. 보행 동선 탭에서 현재 위치를 정지점으로 추가합니다.
  3. 다음 지점으로 이동해 순서대로 추가합니다. 최소 두 지점이 필요합니다.
  4. 이름과 속도를 정하고 동선 만들기를 누릅니다.
  5. 재생·일시정지·타임라인으로 모서리와 시선을 확인합니다.
  6. 영상 녹화를 누르고 탭을 활성 상태로 유지합니다. 완료 후 나타나는 영상 다운로드 링크로 저장합니다.
동선 저장과 영상 파일은 별개입니다.

경로는 프로젝트 JSON에 저장됩니다. WebM/MP4 영상은 브라우저에서 실시간 녹화한 뒤 다운로드해야 생깁니다. 다른 탭으로 이동하면 재생·녹화가 멈출 수 있습니다.

대화로 자동 구성

pedestrian-journey 스킬을 사용해 이 프로젝트에서 입구, 라운지, 회의실 순서의 보행 동선을 만들어 줘. 실제 영역 ID와 통행 가능한 문을 확인하고, 눈높이 1.6m와 초속 1.2m로 설정해 줘. 경로가 연결되지 않으면 구조를 바꾸지 말고 이유를 알려줘.

경로 검사는 모델의 벽·가구·보이드에 대한 검사이며 실제 건물의 접근성·피난 적합성을 인증하지 않습니다.

8

외부 AI 이미지 도구에서 발전시키기

PNG에 레퍼런스 이미지와 마감 지시를 더해 사용하세요. 도구마다 모델과 요금·기능이 다르며, 이 패키지는 외부 서비스를 자동 호출하거나 파일을 업로드하지 않습니다.

구조를 유지하는 이미지 요청 예시

첨부한 3D 캡처의 카메라, 벽·기둥·문·천장, 가구 종류·개수·위치·방향을 유지해 줘. 레퍼런스에서는 지정한 재료와 분위기만 참고해 줘. 변경할 마감은 [대상과 재료], 조명은 [원하는 조건]이야. 구조나 가구를 추가·삭제하지 말고, 표시하지 않은 부분은 유지해 줘.

결과를 받으면 원본과 비교해 문이 없어지거나 가구 개수가 달라지지 않았는지 확인합니다. AI 이미지가 원본 기하를 정확히 보존한다고 가정하지 마세요.

결과를 프로젝트에 보관하기

  1. 이미지·마감 탭에서 원본 작업 뷰를 선택합니다.
  2. 생성된 이미지 버전 추가에서 결과 PNG/JPEG/WebP를 선택합니다.
  3. 버전 메모를 남기고 새 버전으로 저장을 누릅니다.
  4. 다음 수정은 해당 버전을 선택하고 영역·지점을 표시해 지시를 정리합니다.

대화 안의 내장 이미지 도구를 사용하는 스킬도 선택적으로 포함되어 있습니다. 웹 버튼이 모델을 직접 호출하지 않으며, 도구에 모델 선택기가 없으면 특정 모델 사용을 보장하지 않습니다.

프로젝트 보관과 팀 전달

프로젝트 폴더 전체를 복사하세요. 캡처 PNG만 보내면 이미지는 공유할 수 있지만, 뷰 복원·코멘트·동선 편집은 이어 할 수 없습니다.

공개 배포본에는 실제 프로젝트 원본과 작업 기록이 들어 있지 않습니다. 이 가이드의 예제는 합성 모델입니다.

자주 막히는 부분

3D 화면이 열리지 않아요 / WebGL 오류

브라우저의 그래픽 가속 설정을 확인하고, 작업을 저장한 뒤 브라우저를 완전히 종료해 다시 실행합니다. GPU 프로세스가 반복 충돌하면 가속 설정이 켜져 있어도 WebGL이 차단될 수 있습니다. 다른 지원 브라우저에서 확인하세요. 웹 앱 자체가 브라우저 차단을 해제할 수는 없습니다.

WASD가 반응하지 않아요

먼저 3D 화면을 클릭하세요. 입력 칸에 포커스가 있으면 글자가 입력됩니다. 장애물 안에서 시작했다면 실내 뷰 잡기로 시작 위치를 다시 선택하세요. 벽에 닿았다면 옆이나 뒤로 이동할 수 있습니다.

PNG 파일을 어디서 찾나요?

캡처 버튼 아래 저장 경로와 프로젝트의 captures 폴더를 확인합니다. 캡처마다 PNG와 JSON이 함께 생깁니다. 마지막 캡처 PNG 다운로드도 사용할 수 있습니다.

저장 폴더 선택이 안 되거나 취소됐어요

브라우저 지원과 폴더 권한에 따라 다릅니다. 기본 captures 폴더는 계속 사용 가능합니다. 새로고침하면 선택 폴더가 초기화되므로 다시 지정하세요.

도면을 가져왔는데 실내 뷰에 안 보여요

도면 가져오기는 입력 검사 화면입니다. PNG/PDF/DXF에서 모델을 구성하거나 IFC 어댑터를 준비하는 단계가 따로 필요합니다. 새 도면 작업 스킬에 원본과 검토 결과를 전달하세요.

보행 동선을 만들 수 없다고 나와요

정지점이 벽·가구 안에 있거나, 문이 연결되지 않았거나, 보이드를 가로지르는지 확인하세요. 모델에서 통행 가능한 위치로 정지점을 조절하고 다시 만듭니다. 출입구를 임의로 뚫지 마세요.

녹화 파일이 없어요

녹화 완료 또는 일시정지 후 다운로드 링크가 생겼는지 확인하세요. 경로 저장만으로 영상이 만들어지지는 않습니다. 녹화 중 탭을 활성화하고 WebM/MP4를 지원하는 브라우저를 사용하세요.

다른 프로젝트가 열려요

포트가 이미 사용 중이면 새 서버는 다음 포트를 사용합니다. 실행 터미널에 표시된 주소를 사용하고, 다른 프로젝트의 기존 브라우저 탭과 구분하세요.

모델 데이터와 개발자 안내

일반 사용자는 도면과 요구사항을 대화로 전달하면 됩니다. 모델을 직접 다루려면 아래 자료를 참고하세요.

  • spatial-model/1 데이터 형식좌표·축척·영역·벽·가구·높이
  • 프로젝트 생성 상세 안내명령과 원본·미리보기 파일 연결
  • 패키지 스킬 목록입력 검토·모델 구성·이미지·보행
  • 실행 가능한 모델 예제실제 도면이 아닌 합성 모델

모델을 수정한 뒤

node scripts/sync-model.mjs

검증 후 브라우저를 새로고침합니다. 기존 객체 ID와 좌표계는 유지하고, 저장 동선은 현재 모델에서 다시 확인하세요. JSON 오류가 있으면 활성 모델 모듈은 교체되지 않습니다.

기능 변경과 검증

npm ci
npm test
npm run vendor
npm run package

한 프로젝트는 한 층·한 좌표계 기준입니다. 다층 BIM, 임의 곡면 편집, 실제 시공 치수 검증과 피난 분석은 지원 범위에 포함되지 않습니다. 사용한 라이브러리의 라이선스는 저장소의 vendor/THIRD-PARTY-NOTICES.md를 확인하세요.
